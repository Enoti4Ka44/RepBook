# RepBook

**RepBook** — веб-приложение для планирования тренировок, отслеживания спортивного прогресса и ведения тренировочного дневника.

Приложение позволяет создавать собственную библиотеку упражнений, составлять тренировочные планы, фиксировать результаты каждого подхода и анализировать динамику нагрузок.

Проект построен на React и TypeScript.

## Возможности

### Авторизация

- Регистрация и вход в аккаунт.
- JWT-аутентификация.
- Автоматическое обновление access token через refresh token.
- Защищённые маршруты.
- Выход из аккаунта.

### Библиотека упражнений

- Просмотр доступных упражнений.
- Создание собственных упражнений.
- Редактирование и удаление.
- Поиск и фильтрация по мышечным группам.
- Описание упражнений и классификация по типу.

### Планирование тренировок

- Создание тренировочных планов.
- Выбор упражнений из библиотеки.
- Настройка подходов, повторений и рабочего веса.
- Редактирование запланированных тренировок.
- Разминочные подходы и интервалы отдыха.
- Добавление и удаление упражнений.

### Активная тренировка

- Запуск и завершение тренировки.
- Таймер продолжительности занятия.
- Фиксация фактического веса и повторений.
- Отслеживание выполненных подходов.
- Оценка RIR (Reps In Reserve).
- Добавление упражнений и подходов во время тренировки.
- Таймер отдыха с паузой и сбросом.
- Автоматический запуск отдыха после выполненного подхода.
- Звуковое уведомление об окончании отдыха.
- Сохранение результатов на сервере.

### История и аналитика

- История завершённых тренировок.
- Статистика тренировочной активности.
- Расчёт тренировочного объёма.
- Графики нагрузок за 7, 30 и 90 дней.
- Динамика рабочих весов по упражнениям.
- Просмотр результатов отдельных тренировок.

## Установка и запуск

### Требования

- Node.js версии, совместимой с Vite 8.
- npm.
- Запущенный backend.
- Доступный REST API.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Enoti4Ka44/RepBook.git
cd REPOSITORY
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск backend

Backend должен быть доступен по адресу:

```text
http://localhost:8080
```

Базовый путь API:

```text
/api/v1
```

### 4. Настройка прокси

Для локальной разработки запросы `/api` необходимо проксировать на Spring Boot.

Пример настройки `vite.config.ts`:

```typescript
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";
import path from "node:path";

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
  server: {
    proxy: {
      "/api": {
        target: "http://localhost:8080",
        changeOrigin: true,
      },
    },
  },
});
```

Если прокси уже настроен, менять конфигурацию не требуется.

### 5. Запуск frontend

```bash
npm run dev
```

Приложение будет доступно по адресу:

```text
http://127.0.0.1:5173
```

Адрес и порт могут отличаться в зависимости от конфигурации Vite.

### 6. Production build

```bash
npm run build
```

Скомпилированные файлы создаются в директории `dist/`.

Для предварительного просмотра сборки:

```bash
npm run preview
```

## Управление состоянием

Для серверного состояния используется **TanStack Query**.

Это обеспечивает:

- Кэширование ответов API.
- Повторное использование загруженных данных.
- Инвалидацию кэша после изменений.
- Отображение состояний загрузки и ошибок.
- Синхронизацию данных между экранами.

Для HTTP-запросов используется Axios с механизмом обновления JWT-токенов.

## Особенности таймера отдыха

Таймер отдыха работает на стороне клиента.

- Поддерживает ручной запуск.
- Может автоматически запускаться после сохранения подхода.
- Использует запланированную продолжительность отдыха.
- Поддерживает паузу и продолжение.
- Восстанавливает отсчёт после обновления страницы через `localStorage`.
- Очищается после успешного завершения или отмены тренировки.

Таймер не синхронизируется между устройствами.
